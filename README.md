# PK Birthday — The Navodaya Archive

This repository uses a **flat root structure**. Keep every file beside `index.html`.

Required root files: `index.html`, `style.css`, `script.js`, `favicon.svg`, `pk-formal.jpg`, `pk-and-chou.jpg`, `blue-kurta.jpg`, `blue-suit.jpg`, `the-crew.jpg`, `the-evidence.jpg`, `jnv-entrance.webp`, `jnv-signboard.webp`, and `jaane-kyun.mp3`.

The HTML, CSS and JavaScript use root-relative filenames, not `assets/` or `media/` subfolders.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.
